# PRAgent - Polynomial Regression Agent

Implementación orientada a objetos de Regresión Polinomial de segundo grado utilizando el método de Mínimos Cuadrados (Least Squares Regressor) en JADE.

## Componentes
- `DataSet.java`: Contiene el conjunto de datos de entrenamiento (Six Sigma: Batch Size vs Machine Efficiency).
- `PolynomialRegression.java`: Implementación matemática del cálculo de coeficientes beta y determinación de R^2.
- `PRAgent.java`: Agente JADE con comportamiento OneShotBehaviour que orquesta el cálculo, realiza predicciones y finaliza su ciclo de vida.
